## 使用限制與重現

- 不含私人使用者照片、AI 生成圖、可作準確份量／kcal 真值的資料。所有 measured portion 與 reference kcal 均為 null。來源頁提供攝影者與攝影 provenance；未做影像鑑識。
- 選用的兩張 preview 是 Wikimedia 已提供的縮圖，不是我們修改原圖；其雜湊與原圖不同。所有圖片皆未做本機調暗、裁切、旋轉或重新壓縮。
- 使用或分享圖片／含圖 QA screenshot 時保留作者、來源、適用授權及既有加工註記；CC BY-SA 圖片的衍生圖保留相容授權。不要把頁面 footer 的 CC0 metadata 授權套到照片本身。
- 這組素材只用於流程及 UX 驗收，不代表營養估算準確率、不替代 20 張 development/holdout 評估，也不覆蓋 HEIC、手機相機或實機 PWA。
- 登入、上傳、真實 AI、修正、儲存、API 回讀、reload、history、Today、edit/delete 與帳戶隔離須另行取得執行證據。
- 下載最初受 sandbox DNS 及 Wikimedia HTTP 429 影響，失敗記錄保留於暫存目錄；其後使用來源頁明示的 download/thumbnail links 成功。不可把失敗記錄當成空圖片或成功下載。
- 暫存目錄另保留未選用的 `simple-banana.jpg`（一整碟香蕉，Rameshng，[來源](https://commons.wikimedia.org/wiki/File:Banana_in_a_plate.JPG)，[CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/)）；因不是單根食物而改用 Banana-Single。

在素材目錄驗證：

```sh
shasum -a 256 -c SHA256SUMS
```

重新下載須使用每項的直接圖片 URL，寫入對應檔名，再比對 SHA-256；不相符就重新檢查來源版本，不可靜默更新基線。
